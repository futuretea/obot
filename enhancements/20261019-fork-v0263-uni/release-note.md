# fork/v0.26.3-uni 发布说明

这份说明留在仓库里，不发 GitHub Release，不发到仓库外。

## 你会看到的变化

- 页面上的产品名从 “Obot” 变成 “uni”。浏览器标题、按钮和提示都按这个名字显示。
- 登录仍走 Keycloak。登录成功后回到应用，并显示已登录状态。
- 用户数和设备数不再被 100 的上限拦住。

## 这一版不再提供

- 单会话。新登录不会把同一账号的旧登录挤掉，多个登录可以同时留着。
- 0.20 一代的 `obot-tools`。这一版只使用 `obot-providers`。

## 上游从 v0.20.1 到 v0.26.3 带来的变化

- 旧的项目聊天、助手、分享和任务不再提供。升级不会把这些旧数据搬进新版本。
- 新版本可以配置虚拟 MCP、MCP 隧道、本地登录、许可证、LLM 审计日志和设备执行记录。
- 数据库仍用原来的 Postgres。连接串键名不变，Helm 中它从 config 挪到 secret。

## 地址和配置不变

登录地址、环境变量、接口字段和代码标识保持原名。只改了界面上能看见的产品名。
