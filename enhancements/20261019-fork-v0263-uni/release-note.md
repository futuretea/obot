# fork/v0.26.3-uni 发布说明

这份说明留在仓库里，不发 GitHub Release，不发到仓库外。

## 你会看到的变化

- 页面上的产品名从 “Obot” 变成 “uni”。浏览器标题、按钮和提示都按这个名字显示。
- 登录仍走 Keycloak。登录成功后回到应用，并显示已登录状态。
- 用户数和设备数不再被 100 的上限拦住。

## 这一版不再提供

- 单会话。新登录不会把同一账号的旧登录挤掉，多个登录可以同时留着。
- 0.20 一代的 `obot-tools`。这一版只使用 `obot-providers`。

## 上游从 v0.20.1 到 v0.26.3 带来的变化

- v0.22 起不再提供旧的项目聊天、助手、分享和任务。0.20 的 Agent、项目和任务不会自动搬进新版本。
- v0.23 起旧认证 token 弃用，API token 范围有变化；模型与认证组件改在容器里运行。
- v0.24 起可以在应用内做本地登录，并查看、导出 LLM 审计；模型供应商增加 AWS Bedrock、Azure 和通用接口。
- v0.25 起原来的 API key 改为 Agent Auth Scope，并增加用户数、设备数限制和 MCP 隧道。
- v0.26 起现有 MCP 目录和服务会变成虚拟 MCP，一批旧 MCP 接口不再可用。新的 Agent 功能默认关闭；0.20 的旧 Agent 不会让它自动打开，需要时设置 `OBOT_ENABLE_AGENTS=true`。

## 地址和配置不变

登录地址、环境变量、接口字段和代码标识保持原名。只改了界面上能看见的产品名。
